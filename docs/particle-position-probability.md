# Directional probability versus position concentration

This is a conditional calculation from the selected continuum flow derivative,
not a molecular model. It resolves two different meanings of “particles become
more predictable”: orientation of infinitesimal separations can concentrate
near the axis, while the spatial probability density need not concentrate.
The position-density and Gaussian calculations below apply the tangent matrix
as a global affine map to a toy ensemble. The actual theorem supplies a local
flow derivative; it does not establish that an unbounded Gaussian cloud stays
inside a region where the nonlinear flow is represented by that affine map.
Those position probabilities are therefore an exact linear-model comparison,
not predictions for a finite packet in the constructed flow.
The flow-derivative scope and updated source transfer are recorded in
[`axis-flow-derivative.md`](axis-flow-derivative.md) and
`evidence/upstream-refresh/updated-axis-force-sign.json` (OpenAI source pin
`f9e8bc5b38b6e212696e8a30e3e91517af887bbd`). The calculation below is an
elementary probabilistic consequence of that matrix, not a new PDE theorem.

For a fixed `t0 < t < 1`, let `Q=(1-t)/(1-t0)` and use the audited local
deformation with singular values

```
Q^(C/2), Q^(C/2), Q^(-C),       det(F)=1.
```

Rotation in the transverse plane does not change these results. For a smooth
initial position density `rho0`, change of variables gives

```
rho_t(x) = rho0(F^(-1)x) / |det(F)| = rho0(F^(-1)x).
```

In particular, an initially isotropic centered Gaussian with covariance `I`
has covariance eigenvalues `Q^C, Q^C, Q^(-2C)` after the linearized map. Their
product is one, its differential entropy is unchanged, and its peak density is
unchanged. The cloud narrows transversely while stretching axially; this is not
three-dimensional positional concentration or a general reduction of position
uncertainty.

The same Gaussian model makes the positional tradeoff explicit. Let `r>0` be
a fixed transverse radius and `L>0` a fixed axial half-length. Independence of
the Gaussian coordinates gives

```
P(distance_to_axis <= r)
  = 1 - exp(-r^2/(2 Q^C))                         -> 1,

P(inside cylinder of radius r and |z| <= L)
  = (1-exp(-r^2/(2 Q^C))) erf(L Q^C/sqrt(2))
  ~ sqrt(2/pi) L Q^C                              -> 0.
```

Thus nearly all of this model's mass enters any fixed-radius *infinite* tube,
but the mass in a cylinder with fixed finite length tends to zero because the
axial spread grows. This is a precise sense in which transverse position
relative to the axis becomes localized while 3D location, peak density, and
volume do not concentrate. The event depends on the chosen observation window;
it is not an intrinsic increase in certainty for every position question.

There is nevertheless a precise directional-probability consequence under an
explicit extra model. Sample an initial *infinitesimal separation direction*
uniformly from the sphere. For the angle `theta0` to the unoriented axis, set
`mu=|cos(theta0)|`; isotropy makes `mu` uniform on `[0,1]`. Linearized evolution
gives

```
tan(theta_t) = Q^(3C/2) tan(theta0).
```

For a fixed target angle `0 < theta* < pi/2`, write `a=Q^(3C/2)` and
`m=tan(theta*)`. The event `theta_t <= theta*` is equivalent to
`mu >= a/sqrt(a^2+m^2)`. Therefore

```
P(theta_t <= theta*) = 1 - a/sqrt(a^2 + tan(theta*)^2),
```

which tends to one as `t` approaches one. At `Q=1` it reduces to the initial
unoriented spherical-cap probability `1-cos(theta*)`. The exactly transverse
directions form a probability-zero set under this model, although they remain
an important deterministic exception.

This gives a legitimate, model-dependent increase in the probability of an
**orientation event for infinitesimal continuum separations**. The probability
space is an imposed distribution of initial directions. It is not generated by
the Navier–Stokes theorem, does not describe absolute molecular positions, and
does not extend to finite packets near `t=1` without the effective tube and
Hessian bounds still missing from the finite-packet analysis. Interparticle
forces, molecular alignment, phase change and constitutive viscosity are not
modeled.

## Conditional finite-aspect Jeffery director model

There is a related, separate orientation calculation for an ideal rigid
prolate particle. Assume its axis `p` obeys Jeffery's equation in a spatially
uniform axisymmetric strain with axial/transverse eigenvalues
`(2 gamma,-gamma,-gamma)`, with `kappa=(AR^2-1)/(AR^2+1)`. If the axisymmetric
strain history is additionally prescribed as `gamma(t)=C/(2(1-t))`, the polar
angle `beta` satisfies

```
tan(beta(t)) = Q^(3*kappa*C/2) tan(beta(t0)).
```

For an imposed isotropic distribution of initial unoriented directors, the
same spherical-coordinate calculation gives

```
P(beta(t) <= beta_star)
  = 1 - a_kappa / sqrt(a_kappa^2 + tan(beta_star)^2),
    a_kappa = Q^(3*kappa*C/2).
```

For every prolate Jeffery director (`kappa>0`) this probability tends to one as
`Q -> 0` in the ideal model. The rate depends on aspect ratio through `kappa`:
for `AR=10` and `100`, it is `99/101` and `9999/10001`, respectively. The
`kappa -> 1` limit recovers the infinitesimal continuum-direction exponent.
This is a model for *orientation*, with a newly imposed initial-orientation
distribution and a prescribed local strain history. It is not an extension of
the particle-position Gaussian result, a finite-particle theorem for the
OpenAI profile, or a molecular probability statement. In particular, a sphere
(`AR=1`, `kappa=0`) has no distinguished Jeffery director to align.

The algebra and these assumptions are checked by
`python -m tools.check_jeffery_axisymmetric_bridge`; its output is archived in
`evidence/tests/jeffery-axisymmetric-bridge.json`. Experimental and numerical
context for finite fibers, including where local Jeffery theory ceases to
apply, is summarized in [`fiber-vortex-literature-audit.md`](fiber-vortex-literature-audit.md).

The existing nonlinear remainder estimate yields a conditional rate for how
small a certified initial packet must be if the available tube radius and
Hessian bound obey power laws. For `rho(Q)=rho0 Q^r` and `M(Q)/2=O(Q^-kappa)`,
it is sufficient to take `delta(Q)=O(Q^(C+max(r,kappa-1)))`; this tends to zero
for the audited `C>1`. No such endpoint envelopes or constants have been
established for the selected profile. Details and the piecewise derivation are
in [`axis-packet-bound.md`](axis-packet-bound.md).
